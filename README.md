# practice-pm02-integration-testing

Учебный проект для практики ПП.02.01.
Включает модуль расчета цены и модуль логирования.

## Структура проекта
- `/module_A` — Модуль расчета цены (`calc.py`).
- `/module_B` — Модуль логирования (`logger.py`).

## Инструкция по запуску
Проект написан на Python. Для проверки работы модулей выполните скрипты:
```bash
